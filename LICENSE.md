# Licenses

This repository has no single license. Each folder is a separate package
under its own license, kept from its authors: see the license file in the
folder, or the `license` field of its `dub.json` / `dub.sdl` when there is
no file. `index.json` lists the license of every package.

Destiny's changes to a package are under that package's license.

The repository's own files (`index.json`, `README.md`, `.github/`) are under
the Mozilla Public License 2.0; see [LICENSE-MPL](LICENSE-MPL).
